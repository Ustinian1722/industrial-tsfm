# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - Unreleased

Initial public-ready research release containing:

- TimesFM, Chronos, Chronos-2, Moirai-2, PatchTST, and Naive adapters;
- C-MAPSS, UCI Gas Turbine, Tennessee Eastman, and opt-in NASA/IMS contracts;
- target scaling, few-shot adaptation, TimesFM LoRA/PEFT, shift/OOD analysis,
  reliability diagnostics, generalization gaps, and compute trade-offs;
- validation-only model selection and a support/shift/budget adaptation engine;
- reproducible configurations, audit scripts, synthetic tests, documentation,
  and a static IndusTSFM demonstration report.
