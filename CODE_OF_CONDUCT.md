# Code of Conduct

We are committed to making participation in Industrial TSFM welcoming,
professional, and harassment-free for everyone.

Expected behavior includes:

- communicating respectfully and assuming good faith;
- focusing criticism on ideas, code, evidence, and reproducibility;
- welcoming different backgrounds and levels of experience;
- protecting private data, credentials, and unpublished research.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, doxxing, sexualized conduct, and deliberate publication of private or
restricted material.

Project maintainers may edit, remove, or reject contributions that violate
this code or threaten the safety and reproducibility of the project. Report a
concern privately through the repository's GitHub contact or security-reporting
channel once the repository is published; do not post sensitive details in a
public issue.
